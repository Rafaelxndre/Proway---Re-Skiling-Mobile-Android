Repositório com os projetos e atividades do curso de Android (120 horas), desenvolvidos ao longo da trilha de aprendizado.

## Objetivo

Organizar, versionar e publicar a evolução prática do curso, desde os fundamentos até os projetos mais completos com Kotlin e Jetpack Compose.

## Ementa do Curso

1. Fundamentos do Android e ambiente de desenvolvimento
2. Introdução ao desenvolvimento com Kotlin
3. Desenvolvimento de layouts e componentes com Jetpack Compose
4. Navegação e fluxo entre telas
5. Gestão de estado
6. Persistência de dados
7. Padrões de arquitetura no desenvolvimento Android
8. Consumo de APIs e notificações
9. Sensores, hardware e recursos nativos do Android
10. Testes em aplicações Android
11. Background Tasks e publicação
12. Projeto Final 

## Estrutura Atual do Repositório

### 1) 01_Projeto_Introducao_Desenvolvimento_Kotlin
Projeto inicial com foco em fundamentos de Kotlin e estrutura básica de projeto Android.

### 2) Gerenciadorcontatos
Aplicativo Android para gerenciamento de contatos com persistência local e integração com API de CEP.

Destaques:
- Cadastro, edição, busca e exclusão de contatos
- Room (SQLite) para armazenamento local
- Retrofit para consulta de endereço via ViaCEP
- Interface com Jetpack Compose

### 3) SistemaHospedagem
Aplicativo Android com proposta de experiência de hospedagem/resort, com múltiplas telas e navegação.

Destaques:
- Navegação entre páginas (Início, Atrações, Comentários e FAQ)
- Componentes visuais com Jetpack Compose
- Estrutura orientada a estados e fluxo de UI
- Simulação de experiência real de produto

## Como acompanhar

Novos projetos e atividades serão adicionados neste repositório conforme o avanço do curso.

Para abrir um projeto:
1. Entre na pasta do projeto desejado
2. Abra no Android Studio
3. Sincronize o Gradle
4. Execute no emulador ou dispositivo físico
